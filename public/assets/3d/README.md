# Assets 3D ALEX

Déposer les modèles fournis dans ce dossier avec ces noms normalisés :

- `villa-interior.glb` — loft intérieur, choisir une seule des deux copies identiques.
- `characters-cartoon.glb` — personnages cartoon.
- `playground.glb` — structure de jeu.
- `playground-cyprus.glb` — aire de jeu Cyprus.
- `low-poly-home.png` — le fichier intitulé `low_poly_home_1.glb` est détecté comme PNG et doit garder son extension réelle.

Les sources reçues font environ 96 Mo au total. Les modèles ne sont pas encore inclus dans le dépôt : GitHub Contents accepte les fichiers texte, et ce transfert ne permet pas de pousser ces binaires volumineux. Garder les fichiers sources dans la bibliothèque jusqu'à leur transfert par Git LFS ou par l'interface GitHub.
